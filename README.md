# Univerzální responzivní motiv pro SunLight CMS

Motiv pro SunLight CMS 8.3.1+ s responzivním rozložením, nastavitelným textem horní lišty a logem, pravým postranním panelem, světlým/tmavým režimem a moderním výpisem článků.

## Stažení

Použijte tlačítko **Code → Download ZIP** na stránce repozitáře. Po rozbalení nahrajte složku `universal-responsive` do `plugins/templates/` ve své instalaci SunLight CMS.

## Instalace

1. Nahrajte složku `universal-responsive` do `plugins/templates/`.
2. V administraci otevřete **Pluginy → Motivy**, znovu načtěte pluginy a aktivujte „Univerzální responzivní motiv“.
3. V nastavení motivu otevřete **Konfigurovat** a nastavte `header_text`, `logo_url` a případně `logo_alt`.
4. Boxy určené do pravého sloupce přiřaďte do slotu **pravý postranní panel**.
